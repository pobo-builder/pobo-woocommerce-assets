Integrates Pobo Page Builder to display professionally designed product content in WooCommerce.

== Description ==

Pobo Page Builder - WooCommerce integrates the Pobo Page Builder SDK with your WooCommerce store. This plugin allows you to use Pobo's powerful page builder features for creating rich, engaging product descriptions.

= Features =

* Easy integration with Pobo Page Builder
* Simple configuration through WordPress admin
* Automatic site URL detection
* Enable/disable toggle for quick control
* Lightweight and fast

= Requirements =

* WordPress 5.8 or higher
* WooCommerce 5.0 or higher
* PHP 7.4 or higher
* Active Pobo account with Eshop ID

= Configuration =

1. Go to Settings → Pobo Assets
2. Enable the plugin using the checkbox
3. Enter your Eshop ID (found in your Pobo dashboard)
4. Optionally customize the Eshop URL
5. Save changes

== Installation ==

1. Upload the `pobo-woocommerce-assets` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Settings → Pobo Assets to configure

== Frequently Asked Questions ==

= Where do I find my Eshop ID? =

You can find your Eshop ID in your Pobo dashboard after creating an account at pobo.cz.

= Does this plugin work without WooCommerce? =

No, this plugin requires WooCommerce to be installed and active.

= Will this slow down my site? =

No, the SDK script is loaded asynchronously with high fetch priority, ensuring minimal impact on page load times.
